# ИИкона — руководство пользователя

Настройка и эксплуатация подсистем ИИконы — AI-коннектора для 1С:Предприятие 8.

Раздел для пользователей и администраторов: как настроить и запустить.


## Версия 1.6.2 и меню

Руководство обновлено для интерфейса 1.6.2. Исторические снимки измененных форм
подписаны отдельно; новые примеры подключения, поиска и диаграмм сняты в проверочной базе.

| Группа в разделе «ИИкона» | Доступ |
|---|---|
| Работа с ИИ | чат с экспертом, эксперты и диаграммы |
| Знания | база знаний, категории, фрагменты |
| Мониторинг | дашборд, ошибки, статистика и журналы |
| Администрирование | модели, настройки мониторинга, MCP и персональных данных |

Самый короткий путь проверить знания: «Знания» → «База знаний» → выбранная карточка →
«Проверка поиска». Форма показывает найденные фрагменты до обращения к чат-модели.

## С чего начать

**[Начало работы](начало-работы/README.md)** — установка расширения, права, модели и ключ,
первый эксперт и первый вопрос в «Чате с экспертом». Внизу страницы — что проверить, если модель
не отвечает.

## Подсистемы

- **[Эксперты ИИ](эксперты/README.md)** — модель плюс системный промпт: поля карточки,
  как писать промпт, база знаний в ответах.
- **[Агентская петля](агентская-петля/README.md)** — модель сама запрашивает метаданные и
  данные базы: где работает, инструменты, ограничители, что остается в журналах.
- **[Вложения и картинки](вложения/README.md)** — файлы к вопросу в «Чате с экспертом», какие форматы
  их принимают, генерация картинок.
- **[Журнал запросов, расходы и кеш](журнал-запросов/README.md)** — токены и стоимость каждого
  запроса, кеш ответов, сроки хранения.
- **[Анализ ошибок](анализ-ошибок/README.md)** — мониторинг ошибок: настройки, регламенты,
  Telegram, дашборд, журнал, глубокий анализ и
  **[аудитор кода](анализ-ошибок/аудитор-кода.md)** — диагностика по стеку через LLM.
- **[Настройка моделей](настройка-моделей/README.md)** — коннектор ИИ, провайдеры,
  форматы API, авторизация, прокси, модели-эмбеддеры.
- **[RAG](rag/README.md)** — семантический поиск по базе знаний, egress-политики,
  внутренний и внешний бэкенды.
- **[MCP-сервер](mcp-сервер/README.md)** — база 1С как набор инструментов для внешних
  ИИ-агентов: настройка, авторизация, безопасность, аудит.
- **[Диаграммы](диаграммы/README.md)** — генератор диаграмм по описанию или коду,
  форматы, рендеринг через Kroki.
- **[Контроль персональных данных](контроль-персональных-данных/README.md)** — замена ФИО,
  ИНН, телефонов и других ПД подстановками перед отправкой в модели, Telegram и Kroki;
  режимы, доверенный маршрут, журнал.

## Разработчику и вопросы

- **[Для разработчика](для-разработчика/README.md)** — запрос к модели из своего кода, фон,
  вложения, персональные данные, эксперт с базой знаний, агентская петля, диаграмма.
- **[Частые вопросы](faq/README.md)** — стоимость, работа без внешних сервисов, что уходит
  наружу, права, обновление.
