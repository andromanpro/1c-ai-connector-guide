# Частые вопросы

**Сколько это стоит?**
ИИкона бесплатна (MIT). Платите провайдеру моделей по его тарифу. Токены каждого запроса видны
в [журнале запросов ИИ](../журнал-запросов/README.md); стоимость — только если провайдер сам ее
возвращает, как OpenRouter (в долларах).

**Можно работать без внешних сервисов?**
Да. Модель — через Ollama или LM Studio в формате «OpenAI-совместимый», без ключа. Эмбеддер
для [RAG](../rag/README.md) — тоже локальный. [Диаграммы](../диаграммы/README.md) рисует Kroki,
его можно поднять рядом с 1С.

**Что уходит наружу?**
Вопрос, системный промпт, история диалога и вложения — провайдеру модели; уведомления — в
Telegram; код диаграмм — в Kroki. Все это проходит
[контроль персональных данных](../контроль-персональных-данных/README.md): ФИО, ИНН, телефоны
заменяются подстановками, а в режиме «Не отправлять» запрос с находками не уходит вовсе.
Содержимое картинок и PDF контроль не читает.

**Где хранится ключ API?**
В безопасном хранилище БСП, а не в реквизите модели: в списках и отчетах его не видно. Полная
выгрузка базы (`.dt`) содержит и безопасное хранилище — храните ее как секрет. Ключ вводится в
карточке модели и сохраняется при записи карточки.

**Какие права нужны?**
Администратору ИИконы — роль «КИИ полные права», полные права в базе не нужны (с 1.6.1).
Пользователям готовых функций — «КИИ базовые права». Подробнее — в
[начале работы](../начало-работы/README.md#2-выдать-права).

**Модель не отвечает.**
Таблица с частыми причинами — в
[начале работы](../начало-работы/README.md#если-модель-не-отвечает).

**Эксперт не использует базу знаний.**
В карточке эксперта должна быть заполнена таблица «Категории знаний (RAG)», документы —
проиндексированы, эмбеддинги — получены. База знаний подмешивается только в «Тесте ИИ», см.
[эксперты](../эксперты/README.md#база-знаний-в-ответах).

**Как обновить ИИкону?**
Загрузите новый `IIkona_ConnectorAI_v<версия>.cfe` поверх установленного расширения в
«Расширениях». Модели, эксперты, база знаний и настройки остаются. После обновления до 1.6.1
откройте и запишите любую модель ИИ: так появятся регламенты очистки (см.
[журнал запросов](../журнал-запросов/README.md#сколько-хранится)).

**Почему в Telegram пришли ошибки автотестов?**
Мониторинг отличает автотест по маркеру в стеке записи журнала регистрации. Тесты ИИконы
вызывают боевой код, и часть их записей стека не содержит. Гоняйте тесты на базе, где
[мониторинг](../анализ-ошибок/README.md) и уведомления выключены.

**Как подключить ИИкону к внешнему ИИ-агенту?**
Через [MCP-сервер](../mcp-сервер/README.md): база 1С становится набором инструментов для
внешнего агента.
