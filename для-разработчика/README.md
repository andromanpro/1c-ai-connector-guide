# Для разработчика

Как звать ИИкону из своего кода. Все функции — серверные, в общем модуле `КИИ_КоннекторИИ`
и соседних модулях расширения.

Код, который вызывает ИИкону, живет в своем расширении: основная конфигурация не видит
модули расширения при компиляции. Из кода конфигурации — через
`ОбщегоНазначения.ВызватьФункциюКонфигурации` БСП.

## Запрос к модели

```bsl
Модель = Справочники.КИИ_МоделиИИ.НайтиПоНаименованию("Claude Opus 5.5");
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, "Сформулируй назначение документа в двух предложениях");

Если Ответ.ЭтоОшибка Тогда
	ОбщегоНазначения.СообщитьПользователю(Ответ.ТекстОшибки);
Иначе
	ТекстОтвета = Ответ.ТекстОтвета;
КонецЕсли;
```

`Промпт` — строка или структура:

| Поле | Что передать |
|---|---|
| `СистемныйПромпт` | роль и правила ответа |
| `ПользовательскийПромпт` | строка вопроса или массив элементов контента (см. «Вложения») |
| `ИсторияСообщений` | массив прошлых сообщений диалога, необязательно |

Что в ответе: `ЭтоОшибка`, `ТекстОшибки`, `ТекстОтвета`, токены (`ВходныеТокены`,
`ВыходныеТокены`, `ВсегоТокенов`), `ВремяОтветаСекунд`, `СтоимостьОтвета`, `МодельОтвета`,
`ПричинаЗавершения`.

`ЗапросКМодели` не бросает исключений на ошибках сети и провайдера: проверяйте `ЭтоОшибка`.
Каждый вызов попадает в [журнал запросов ИИ](../журнал-запросов/README.md) и проходит
[контроль персональных данных](../контроль-персональных-данных/README.md) и
[кеш](../журнал-запросов/README.md#кеш-ответов), если он включен у модели.

## Запрос в фоне

Из формы долгий запрос лучше отдать фоновому заданию, чтобы форма не замирала:

```bsl
&НаСервере
Функция ЗапуститьЗапросНаСервере(Знач Модель, Знач Вопрос)
	Возврат КИИ_КоннекторИИ.ЗапросКМоделиВФоне(Модель, Вопрос);
КонецФункции
```

Функция возвращает описание длительной операции БСП: ждите его
`ДлительныеОперацииКлиент.ОжидатьЗавершение`. По адресу результата лежит та же структура, что
у `ЗапросКМодели`, плюс `ТекстОтветаДляЧеловека` — ответ, в котором подстановки персональных
данных возвращены к исходным значениям.

## Персональные данные в ответе

Модель видит подстановки вместо ФИО и ИНН, и в ответе тоже будут подстановки. Чтобы показать
ответ человеку с исходными значениями, передайте контекст контроля и восстановите ответ:

```bsl
Контекст = КИИ_КонтрольПерсональныхДанных.НовыйКонтекст();
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, Промпт, Контекст);
Если Не Ответ.ЭтоОшибка Тогда
	ДляЧеловека = КИИ_КонтрольПерсональныхДанных.ВосстановитьДляЧеловека(Ответ.ТекстОтвета, Контекст).Текст;
КонецЕсли;
```

Восстанавливайте только то, что покажете человеку. В регистры, журналы и в следующий запрос к
модели кладите `ТекстОтвета` с подстановками.

## Вложения

```bsl
Контент = КИИ_КоннекторИИ.ПостроитьКонтентМассив();
Контент.Добавить(КИИ_КоннекторИИ.ПостроитьКонтентТекст("Что на картинке?"));
Контент.Добавить(КИИ_КоннекторИИ.ПостроитьКонтентИзображениеДанные(ДвоичныеДанные, "image/png"));
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, Новый Структура("ПользовательскийПромпт", Контент));
```

| Конструктор | Для чего |
|---|---|
| `ПостроитьКонтентТекст(Текст)` | текстовая часть |
| `ПостроитьКонтентИзображениеДанные(Данные, MIME)` | картинка из двоичных данных |
| `ПостроитьКонтентИзображениеURL(URL)` | картинка по ссылке или data-URI |
| `ПостроитьКонтентДокументДанные(Данные, MIME, ИмяФайла)` | документ, например PDF |

Какие форматы API принимают файлы — на странице [вложения](../вложения/README.md).

## Эксперт и база знаний

Эксперт — это модель и системный промпт. База знаний эксперта подмешивается в промпт
функцией RAG:

```bsl
Модель = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Эксперт, "Модель");
ПромптЭксперта = ОбщегоНазначения.ЗначениеРеквизитаОбъекта(Эксперт, "ОписаниеЭксперта");

Промпт = Новый Структура;
Промпт.Вставить("СистемныйПромпт", КИИ_RAG.ПодмешатьЗнанияЭксперта(Эксперт, Вопрос, ПромптЭксперта));
Промпт.Вставить("ПользовательскийПромпт", Вопрос);
Ответ = КИИ_КоннекторИИ.ЗапросКМодели(Модель, Промпт);
```

Если у эксперта нет категорий знаний или поиск не сработал, функция возвращает промпт
эксперта без изменений. Как устроен отбор — на странице [эксперты](../эксперты/README.md#база-знаний-в-ответах).

## Агентская петля

Модель с флажком «Поддерживает инструменты» может сама запрашивать метаданные и данные:

```bsl
Опции = КИИ_АгентАнализа.ОпцииПоУмолчанию();
Опции.Инструменты = КИИ_АгентАнализа.ИнструментыПоУмолчанию(); // или свой список имен
Итог = КИИ_АгентАнализа.ВыполнитьАнализСИнструментами(Модель, Промпт, Опции);
```

В `Итог` — `ЭтоОшибка`, `ТекстОшибки`, `ТекстОтвета`, `Раундов`, `ВызововИнструментов`,
`ОборваноПоЛимиту`. Ограничители и список инструментов — на странице
[агентская петля](../агентская-петля/README.md). Проверить флажок у модели —
`КИИ_АгентАнализа.МодельПоддерживаетИнструменты(Модель)`.

## Диаграмма из кода

```bsl
Генератор = Обработки.КИИ_ГенераторДиаграмм.Создать();
Результат = Генератор.СгенерироватьДиаграмму("Покажи связи РегистрСведений.КИИ_ЛогЗапросовИИ", , Эксперт);
Если Не Результат.ЭтоОшибка Тогда
	КодДиаграммы = Результат.КодДиаграммы; // SVG - в Результат.SVGТекст
КонецЕсли;
```

Первый параметр — описание или готовый код диаграммы; второй — оформление (адрес Kroki, тема,
таймаут). Подробнее — на странице [диаграммы](../диаграммы/README.md).

## Регламенты очистки

Если свое расширение ставит ИИкону в базу программно, после записи моделей вызовите
`КИИ_КоннекторИИ.ОбеспечитьРегламентыОчистки()`: регламентные задания расширения не бывают
предопределенными, и без этого вызова очистка кеша, аудита MCP и журнала контроля
персональных данных не создается. Функция идемпотентна.
